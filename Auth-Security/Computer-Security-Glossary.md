## Mémo Glossaire Sécurité Informatique

### 1. **Analyse de Risque** 📊

- **Définition** : Ensemble du processus permettant l'identification, l'évaluation et le traitement des risques.
- **Importance** : Essentielle pour anticiper et gérer les menaces potentielles.

### 2. **Attaque de l'Homme-du-Milieu (Man-in-the-Middle)** 🚨

- **Définition** : Attaque où un attaquant intercepte ou modifie des informations entre deux parties communicantes.
- **Exemple** : Intercepter des données sensibles en HTTPS si le certificat SSL n'est pas valide.

### 3. **Attaque par Rejeu** 📝

- **Définition** : Attaque où un attaquant utilise des informations d'authentification volées pour usurper une identité.
- **Prévention** : Utiliser des tokens à usage unique (OTP) ou l'authentification multifacteur.

### 4. **Authentification** 🔒

- **Définition** : Processus de vérification de l'identité d'un utilisateur via un moyen d'authentification.
- **Types** : Mot de passe, clé privée, empreinte digitale, etc.

### 5. **Authentification Multifacteur (MFA)** 🔒

- **Définition** : Authentification utilisant plusieurs facteurs (connaissance, possession, inhérent).
- **Avantages** : Renforce la sécurité en rendant plus difficile l'usurpation d'identité.

### 6. **Critères Communs (CC)** 📈

- **Définition** : Cadre international pour l'évaluation de la sécurité des produits informatiques.
- **Utilité** : Permet de garantir un niveau de sécurité standardisé.

### 7. **CNIL** 📊

- **Définition** : Commission nationale de l'informatique et des libertés, chargée de protéger les données personnelles en France.
- **Rôle** : Veille au respect du RGPD et des lois sur la protection des données.

### 8. **Code PIN** 🔑

- **Définition** : Code d'identification personnel, souvent utilisé pour des transactions sécurisées.
- **Utilité** : Ajoute une couche de sécurité supplémentaire pour l'accès à des ressources sensibles.

### 9. **Coffre-fort de Mots de Passe** 🗝️

- **Définition** : Logiciel sécurisé pour stocker et gérer les mots de passe.
- **Avantages** : Permet de générer et stocker des mots de passe forts sans les mémoriser.

### 10. **Compte à Privilèges** 🚫

- **Définition** : Compte disposant de droits élevés sur un système d'information.
- **Risque** : Si compromis, peut entraîner des conséquences graves.

### 11. **CSPN** 📈

- **Définition** : Certification de sécurité de premier niveau, garantissant un niveau minimal de sécurité.
- **Utilité** : Facilite la conformité aux exigences de sécurité.

### 12. **Facteur d'Authentification** 🔒

- **Définition** : Élément utilisé pour prouver une identité (connaissance, possession, inhérent).
- **Exemples** : Mot de passe, clé USB, empreinte digitale.

### 13. **FIDO U2F et FIDO 2** 🔒

- **Définition** : Normes d'authentification simplifiant l'utilisation de l'authentification multifacteur.
- **Avantages** : Offrent une sécurité renforcée avec des clés physiques ou des appareils.

### 14. **Hameçonnage (Phishing)** 🚨

- **Définition** : Technique frauduleuse visant à obtenir des informations sensibles en se faisant passer pour un tiers de confiance.
- **Prévention** : Être vigilant avec les liens et les pièces jointes suspects.

### 15. **IPsec** 🔒

- **Définition** : Protocole de communication sécurisée pour protéger les flux réseau.
- **Utilité** : Utilisé pour les réseaux VPN.

### 16. **Kerberos** 🔒

- **Définition** : Protocole d'authentification basé sur des tickets.
- **Utilité** : Utilisé pour l'authentification dans les réseaux d'entreprise.

### 17. **Moyen d'Authentification** 🔑

- **Définition** : Élément utilisé pour prouver une identité (mot de passe, clé privée, etc.).
- **Importance** : Doit être sécurisé pour éviter les usurpations.

### 18. **OTP (One-Time Password)** 🔒

- **Définition** : Mot de passe à usage unique, généralement envoyé par SMS ou via une application.
- **Avantages** : Réduit le risque d'usurpation d'identité.

### 19. **Protocole d'Authentification** 🔒

- **Définition** : Protocole permettant de vérifier l'authenticité d'une identité.
- **Exemples** : Kerberos, OAuth.

### 20. **RGPD (Règlement Général sur la Protection des Données)** 📊

- **Définition** : Règlement européen protégeant les données personnelles.
- **Importance** : Oblige les entreprises à respecter des normes strictes de protection des données.

### 21. **RGS (Référentiel Général de Sécurité)** 📈

- **Définition** : Cadre de référence pour la sécurité des systèmes d'information.
- **Utilité** : Aide à garantir un niveau de sécurité élevé.

### 22. **TLS (Transport Layer Security)** 🔒

- **Définition** : Protocole de communication sécurisée pour protéger les flux réseau.
- **Utilité** : Utilisé pour HTTPS, garantit la confidentialité et l'intégrité des données.
